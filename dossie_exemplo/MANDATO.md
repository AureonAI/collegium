# MANDATO — Exemplo Ltda (BPO financeiro)

## O que a entidade faz
Escritório que presta serviço financeiro terceirizado para pequenas empresas. A equipe COLLEGIUM
concilia o extrato bancário de cada cliente com o razão (lançamentos do ERP) uma vez por mês.

## Para quem
Clientes do escritório. Quem responde pela entrega é o sócio responsável (Patronus).
